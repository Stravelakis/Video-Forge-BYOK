## v0.4.0-beta.1: the first public test version of Video Forge

| | English | Devenglish |
|---|---|---|
| ✨ New | You can download Video Forge from GitHub and install it like any Windows app. | First tagged release; `release.yml` builds the public NSIS installer and portable exe on `windows-latest` |
| ✨ New | The app tells you, at most once a day, when a newer version is out, with a link to it. Nothing downloads by itself. | Main-process check of the GitHub Releases API (`tools/lib/updateCheck.mjs`), cached in `update-check.json`; the window's content policy is unchanged |
| ✨ New | Settings shows which version you have. | `app:info` IPC: version + build kind from the packaged `package.json` |
| ✨ New | Make characters part by part: lock what you like, shuffle the rest, add tattoos, freckles and outfits, and let an AI suggest changes you can keep or throw away. | Character creator phases 1-3: per-character files, locks, marks, eye quirks, AI box with field-level validation |
| ✨ New | A speaker can be a portrait picture that talks. | `portraitPath` speakers, `remotion/portrait` + `PortraitView`, time-only rig animation |
| 🔧 Fixed | Saved projects keep your directions, blur and colour look, and a new project starts clean. | `directions` in project fields; autosave uses the project field list; `blankProject()` on New/Open |
| 🔧 Fixed | The app checks every file a video uses before rendering it. | `assertRenderJobPaths`; HyperFrames page values forced to numbers, fixed words or escaped |
| 🔧 Fixed | Your shared keys file can't be wiped by accident. | Unreadable shared-keys file is never overwritten; other apps' keys kept |
| ⚠️ Heads up | This is a test version. Windows will warn that the app is not signed: click **More info**, then **Run anyway**. | Unsigned (SignPath not set up yet). No automated smoke test exists yet (STANDARDS §2 gate 7: flagged for this beta). |
| ⚠️ Heads up | Brand packs, music and some character moves are not included. | Public build excludes `brands/`, `music/` and the Mixamo-derived `motions.json` + `models/` (licence) |

**Download:** the `Video Forge Setup` installer below (most people), or the portable exe (no install). · **Licence:** [FAL v1.2](https://github.com/Stravelakis/Video-Forge-BYOK/blob/main/LICENSE): free to use, credit "Made with Video Forge" on published videos. · **Changes in full:** [CHANGELOG.md](https://github.com/Stravelakis/Video-Forge-BYOK/blob/main/CHANGELOG.md)
